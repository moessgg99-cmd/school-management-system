# 🏫 Modern School Management System

A comprehensive, real-time administrative dashboard for modern educational institutions. Built with the TALL stack (Tailwind, Alpine.js, Laravel).

## 🚀 Live Demo
**Link:** https://school-management-system-eosin-one.vercel.app/

## ✨ Key Features
*   **User Authentication:** Custom registration and login system with LocalStorage persistence.
*   **Student Management:** Complete enrollment module for adding and managing student data.
*   **Attendance Tracking:** Dynamic daily attendance management.
*   **Teacher Directory:** Faculty records with automated class schedules.
*   **Academic Performance:** Exam mark entry with real-time pass/fail logic and analytics.
*   **Library & Finance:** Asset tracking and student fee collection monitoring.
*   **Interactive Dashboard:** Visual data analytics using **Chart.js**.

## 🛠️ Tech Stack
*   **Framework:** [Laravel 11](https://laravel.com)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com)
*   **Interactivity:** [Alpine.js](https://alpinejs.dev)
*   **Charts:** [Chart.js](https://chartjs.org)
*   **Deployment:** [Vercel](https://vercel.com)
